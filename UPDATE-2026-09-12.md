# Arcanist update — 12 Sep 2026

Source checked against the supplied saved Arcanist wiki page from 12 Sep 2026.

## Added / restored

- All 13 released Exchange upgrades are present in the calculator.
- Current documented Exchange cost tables are used for next-level and remaining costs.
- Exchange currencies are included in Total Resources again.
- The optimizer now treats documented Exchange purchases as priced candidates.
- Exchange icons already present in the repository are wired to the restored rows.
- Save schema is v5 and packed share links use format marker `t`.
- The negative Exchange Timer effect now renders as `-2` rather than `+-2`.

## Deliberately not guessed

The supplied page lists Batch 2 data that is not numerically complete enough for the calculator engine:

- Drift Rune altar: unlock is documented, but cycle/upgrade tables are absent.
- Echo Rune altar: unlock is documented, but cycle/upgrade tables are absent.
- Bug Magnet: effect, duration and cast cost are documented, but its potency-cost table is absent.
- Other newly listed spells still contain `???` values.
- Rows explicitly marked WIP are excluded.

The UI now calls these gaps out directly.

## Source conflict

The Exchange summary lists Gemini Star Cap as max level 20, while its detailed cost table ends at level 10 and totals the row there. This build uses max level 10 rather than inventing costs for levels 11–20.

## Follow-up calculator pass

- Named WIP Essence upgrades are now level inputs even when their costs are unknown.
- Ultra Crit uses the current 8x base; Super/Ultra Shiny use the v7.1.2 +5/+7 nested bonuses.
- Regeneration/respawn, attack speed, weaken/stun negation and the new loot/crit/shiny effects feed the existing engine.
- Arcanist Spell Power is available as a WIP Exchange input and multiplies spell active/passive effects at the end of the existing spell formula.
- Unknown prices stay unpriced and do not contaminate resource totals; the optimizer can still rank their raw benefit.
- GitHub Pages base is configured for `/arcanist-calc/`.
